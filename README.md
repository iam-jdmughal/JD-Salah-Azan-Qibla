# 🕋 JD Salah, Azan Qibla

A premium, high-performance Android app for prayer times and Qibla direction, built with Jetpack Compose.

## 🚀 Key Features
- **Accurate Prayer Times**: Customizable calculation methods and offsets.
- **Qibla Finder**: Responsive compass for locating the Kaaba.
- **Azan Notifications**: Reliable scheduling with custom sound support.
- **Premium Design**: Dark/Light mode with glassmorphism and Islamic patterns.

## 🛠️ Build APK
Run the following command in your terminal:
```powershell
.\gradlew clean assembleDebug
```
**APK Location**: `app/build/outputs/apk/debug/app-debug.apk`
